# User Activity Analysis: Free vs. Premium

## Project Overview

This project focuses on analyzing user activity within an e-learning platform to understand the behavioral differences between Free and Premium users.

The goal is to explore how users interact with the platform, identify patterns in engagement and learning behavior, and uncover opportunities to encourage more Free users to upgrade to a Premium subscription.

Through Exploratory Data Analysis (EDA), this project aims to transform user activity data into actionable business insights that can support data-driven decisions.

## Business Questions

The analysis is guided by the following business questions:

- How do Free and Premium users differ in their engagement with the platform?
- Which activities are more common among Premium users?
- Do Premium users demonstrate higher learning engagement or platform retention?
- What behavioral patterns distinguish users who are more likely to upgrade?
- Which features or learning activities could encourage Free users to become Premium subscribers?
- How can the platform improve its user conversion strategy?

## 📊 Exploratory Data Analysis (EDA)

The EDA will focus on understanding the structure, quality, and characteristics of the user activity dataset.

The analysis will explore:

### 1. Data Understanding
- Dataset structure and dimensions.
- Data types and variable descriptions.
- Missing values and duplicate records.
- Identification of relevant user activity metrics.

### 2. User Segmentation
- Free vs. Premium user distribution.
- Comparison of user activity across subscription types.
- Analysis of learning engagement and platform usage.

### 3. Engagement Analysis
- Frequency of platform usage.
- Learning activity patterns.
- Differences in user engagement.
- Identification of highly engaged Free users.

### 4. Premium Conversion Opportunities
- Exploration of behavioral patterns associated with Premium subscriptions.
- Identification of potential conversion indicators.
- Analysis of activities that may encourage subscription upgrades.
- Business recommendations to improve Premium conversion.
